# AI-Powered AML Investigator Copilot

An AI-powered financial crime investigation platform that combines traditional AML transaction monitoring with machine learning, graph analytics, Retrieval-Augmented Generation (RAG), and LLM-based investigator assistance.

## Project Overview

The project demonstrates how AI can support AML investigators by identifying potentially unusual transaction patterns, prioritizing alerts, analyzing customer and counterparty relationships, retrieving relevant AML guidance, and generating structured investigation insights.

The system is designed around a **human-in-the-loop** approach: AI assists with analysis and prioritization, while the final investigation decision remains with the human investigator.

## Core Capabilities

* Real-time transaction monitoring
* Rule-based AML detection
* ML-based risk scoring
* Behavioural anomaly detection
* Transaction and counterparty graph analysis
* AI-generated investigation summaries
* RAG-based AML knowledge retrieval
* LLM-powered investigator assistance
* Human-in-the-loop case review
* Investigator dashboard

## Technology

Python | SQL | Pandas | Scikit-learn | NetworkX/Neo4j | LLMs | RAG | Vector Database | LangGraph | Streamlit

> **Note:** This is a learning and portfolio project using synthetic data. It does not use real customer or confidential banking information.
